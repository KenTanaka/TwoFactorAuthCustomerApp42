# TwoFactorAuthCustomerApp44

EC-CUBE 4.4（Symfony 7.4）向けの会員向けアプリ認証（TOTP）プラグインです。親プラグイン `TwoFactorAuthCustomer44` が必要です。

- プラグインコード: `TwoFactorAuthCustomerApp44`
- Composer: `ec-cube/twofactorauthcustomerapp44`
- 依存: `ec-cube/twofactorauthcustomer44`

## ブランチ運用

- `4.2` / `4.3`: `TwoFactorAuthCustomerApp42`
- `4.4`: `TwoFactorAuthCustomerApp44`（Attribute / ORM 3 / PHP 8.2+）
